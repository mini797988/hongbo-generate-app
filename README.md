# 브릿지 커피 홍보 자동화

가게 사진을 인스타그램용으로 바꾸고, 채널별 홍보 문구까지 한 번에 만들어 주는 프로그램입니다.
더블클릭 한 번으로 실행됩니다.

## 하는 일

1. **사진 변환**: `자료` 폴더의 jpg, png 사진을 1080 x 1080 정사각형으로 만듭니다.
   - 사진 가운데를 기준으로 자르고, 늘리거나 찌그러뜨리지 않습니다.
   - 오른쪽 아래에 로고를 작게 넣습니다. 로고 둘레는 반투명 흰 바탕입니다.
   - 로고 파일이 없으면 로고 없이 진행합니다.
   - 원본 사진은 건드리지 않습니다.
2. **홍보 문구 만들기**: `가게 정보.txt`를 읽어 세 채널 글을 만듭니다.
   - 인스타그램: 감성형 / 정보형 / 이벤트형 + 해시태그 10개
   - 네이버 블로그: 제목, 본문, 해시태그
   - 카카오톡 단골 공지: 3줄 이내

결과는 모두 `완성` 폴더에 저장됩니다.

- 사진: `오늘날짜_번호.jpg` (예: `20261021_01.jpg`)
- 문구: `홍보문구.txt`

## 폴더 구성

| 이름 | 설명 |
|---|---|
| `자료/` | 변환할 사진, `로고.png`, `가게 정보.txt`, `내 말투.txt` |
| `완성/` | 결과물이 저장되는 곳 |
| `사진변환.py` | 프로그램 본체 |
| `실행.bat` | 더블클릭용 실행 파일 |
| `브릿지카페.ico` | 바탕화면 바로가기 아이콘 |
| `사용설명서.txt` | 매주 쓰는 방법 (비개발자용) |
| `CLAUDE.md` | Claude와 작업할 때의 규칙 |

## 준비물

- Windows
- Python 3.12 + Pillow (사진 처리)
- (선택) `anthropic` 패키지와 API 키 (AI가 문구를 쓰고 싶을 때)

```bash
python -m pip install Pillow anthropic
```

## 실행 방법

`실행.bat`를 더블클릭하거나, `홍보자동화` 폴더에서 아래 한 줄을 실행합니다.

```bash
& "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" 사진변환.py
```

## 매주 바꾸는 것

1. `자료` 폴더에서 지난주 사진을 옮기고, 이번 주 사진을 넣습니다.
2. `자료/가게 정보.txt`의 "이번 주 홍보할 것:" 아래만 고칩니다. 줄 맨 앞에 `-`를 붙여 적습니다.
3. 실행합니다.

자세한 순서와 문제 해결은 [사용설명서.txt](사용설명서.txt)를 보세요.

## 문구 만드는 방식

- **API 키가 없을 때 (기본)**: `가게 정보.txt`의 내용을 정해진 틀에 끼워 넣습니다. 가게 정보에 적은 내용만 사용하고, 없는 내용은 지어내지 않습니다.
- **API 키가 있을 때**: 프로젝트 폴더에 `api키.txt`를 만들어 키를 붙여 넣으면, Claude가 `내 말투.txt`의 말투를 참고해 새로 씁니다. 실패하면 기본 틀로 대신 만듭니다.

`api키.txt`는 `.gitignore`에 들어 있어 GitHub에 올라가지 않습니다. 키를 다른 사람에게 보여 주지 마세요.

## 알아둘 점

- 같은 날 여러 번 실행하면 사진이 번호를 이어 가며 계속 쌓입니다.
- `홍보문구.txt`는 실행할 때마다 덮어씁니다.
- 기본 틀 방식의 블로그 글은 450자 안팎으로, 분량은 `가게 정보.txt`에 적은 내용에 따라 달라집니다.
